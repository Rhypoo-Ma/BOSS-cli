# BOSS-cli 筛选 Playbooks

## 新招呼初筛

**目标**：对指定岗位的"新招呼 + 未读"候选人，逐个查看在线简历，按关键词判断是否发送"求简历"。

**命令模板**：

```bash
./BOSS-cli scan-resumes "岗位名称" \
  --filter="新招呼" \
  --unread \
  --keyword="人力资源,招聘,SSC,员工关系,绩效管理,组织行为,职能岗" \
  --message="求简历" \
  --ocr \
  --exclude-job-title \
  --max=0
```

**参数说明**：

| 参数 | 含义 | 示例 |
|---|---|---|
| `岗位名称` | 要筛选的岗位，必须和 BOSS 页面显示的一致 | `"Kimi HR实习生（招聘+SSC）"` |
| `--filter` | 沟通状态筛选 | `"新招呼"` |
| `--unread` | 只筛未读消息 | 布尔开关 |
| `--keyword` | 逗号分隔的关键词，命中任意一个即匹配 | `"人力资源,招聘,SSC"` |
| `--message` | 匹配后自动发送的消息 | `"求简历"` |
| `--ocr` | 开启 OCR 识别在线简历 canvas 内容（macOS  only） | 布尔开关 |
| `--exclude-job-title` | 过滤掉仅因岗位名产生的噪音匹配 | 布尔开关 |
| `--max` | 最大扫描人数，`0` 表示不限制 | `--max=50` |
| `--min-grade` | 最低毕业年份，从简历文本中提取 | `--min-grade=2027` |
| `--schools` | 逗号分隔的学校关键词，简历中出现任一即通过 | `--schools="清华,北大,浙大"` |

**执行逻辑**：

1. 切换到指定岗位 + 沟通状态 + 未读筛选。
2. 收集该状态下的所有候选人。
3. 对每个候选人：
   - 点开在线简历；
   - OCR 识别简历正文；
   - 用关键词列表搜索；
   - 若命中任意关键词，发送 `--message` 指定的消息；
   - 若未命中，继续下一个人。
4. 若指定 `--min-grade`，会从简历文本中提取毕业年份（支持"2027届"/"27届"/"2027年毕业"/"27年应届生"等），仅当年份 >= 该值时才算符合。
5. 若指定 `--schools`，会从简历文本中提取学校信息，仅当包含任一学校关键词时才算符合。
6. 输出每个人的匹配结果、毕业年份、学校和发送状态。

**注意事项**：

- OCR 每个候选人约 5–15 秒，大量候选人时请合理设置 `--max` 或放后台执行。
- 岗位名称必须准确，建议先用 `./BOSS-cli list-jobs` 确认。
- `--exclude-job-title` 会过滤包含完整岗位名的行，避免"AI达人营销"这类岗位名本身带关键词造成的误匹配。
- 关键词可根据岗位调整，后续可扩展为不同岗位的专用关键词包。

**已验证案例**：

- `Kimi HR实习生（招聘+SSC）` / 新招呼 / 未读 / 关键词"人力资源,招聘,SSC,员工关系,绩效管理,组织行为,职能岗" → 2 人全部命中"人力资源"，均已发送"求简历"。
